- 适用版本：SiYuan `v3.8.3`
- 官方仓库同步到：`siyuan-note/siyuan@master` + Release `v3.8.3`（2026-09-13）
- 最后核对：2026-09-13
- 稳定性：stable
- 权威来源：
  - <https://github.com/siyuan-note/siyuan/blob/master/docs/SY-FORMAT.zh-CN.md>
  - [块模型与属性规范.md](块模型与属性规范.md)

## 1. 属性使用基本原则

1. **`custom-` 前缀规范**：思源严格要求所有用户级和第三方插件的属性必须以 `custom-` 开头。
2. **轻量化**：仅存储轻量状态与元数据（标志位、枚举值、时间戳、短关联 ID），避免大块长文。
3. **防御性读取**：在前端提取属性时，必须做好空值检查（`attrs?.["custom-key"] ?? defaultValue`）。

## 2. 系统与官方常见属性清单

| 属性名 | 适用块类型 | 语义与取值 | 注意事项 |
|---|---|---|---|
| `tabs-active-id` | `tabs` (选项卡容器) | 当前激活展示的选项卡子块 ID (`NodeTabItem`) | 切换 Tab 时内核自动维护 |
| `tabs-position` | `tabs` (选项卡容器) | 选项卡标签显示位置（`"top"`, `"left"` 等） | 影响编辑器渲染布局 |
| `custom-avs` | 全部块 | 该块关联的属性视图（AV）ID 列表 | 绑定多维数据库时使用 |
| `custom-sy-fullwidth` | `d` (文档根块) | 文档是否开启全宽阅读模式（`"true"` / `"false"`） | 影响编辑排版宽度 |
| `custom-sy-readonly` | `d` (文档根块) | 文档只读状态锁定（`"true"` / `"false"`） | 锁定后禁止编辑输入 |
| `custom-hidden` | `d` (文档根块) | 是否在左侧文档树中隐藏该文档 | 仅影响界面树形展示 |
| `custom-heading-mode` | `query_embed` (嵌入块) | 是否隐藏嵌入标题下方的下级子块（`"0"` 显示，`"1"` 隐藏） | 控制嵌入展示层级 |
| `custom-riff-decks` | 全部块 | SRS 闪卡卡包 ID 列表 | 闪卡复习与制卡管理 |
| `custom-dailynote-{yyyymmdd}` | `d` (文档根块) | 日记专属标记，键名直接携带日期字符串 | 快速检索和日记归档 |
| `custom-data-assets` | `widget` (挂件块) | 挂件引用的本地资源相对路径 | 挂件打包与迁移 |
| `data-export-html` | `widget` (挂件块) | 导出 HTML 时替换挂件的原生 HTML 内容 | 保证导出离线可用 |
| `data-export-md` | `widget` (挂件块) | 导出 Markdown 时替换挂件的 Markdown 文本 | 保证导出格式干净 |

## 3. 插件自定义属性设计最佳实践

### 3.1 命名空间范式

```ts
// 推荐的属性命名模式：custom-${插件唯一标识}-${业务属性名}
const ATTR_KEY_SYNC_STATE = "custom-myplugin-sync-state";
const ATTR_KEY_EXTERNAL_ID = "custom-myplugin-external-id";
```

### 3.2 批量读写与过滤

```ts
import { fetchSyncPost } from "siyuan";

// 批量写入属性
export async function markBlocksReviewed(blockIDs: string[]) {
  for (const id of blockIDs) {
    await fetchSyncPost("/api/attr/setBlockAttrs", {
      id,
      attrs: {
        "custom-workflow-status": "reviewed",
        "custom-workflow-reviewer": "alice"
      }
    });
  }
}
```
