# 调试与发布流程

- 适用版本：SiYuan `v3.8.3`
- 官方仓库同步到：`siyuan-note/siyuan@master` + Release `v3.8.3`（2026-09-13）
- 最后核对：2026-09-13
- 稳定性：stable
- 权威来源：
  - <https://github.com/siyuan-note/plugin-sample>
  - <https://github.com/siyuan-note/bazaar>

## 1. 本地开发与调试

### 1.1 软链接开发环境
将插件项目根目录软链接（或拷贝）到思源测试工作空间的插件目录：
- 路径格式：`<思源工作空间>/data/plugins/<插件仓库名>`
- Windows PowerShell 创建符号链接示例：
  ```powershell
  New-Item -ItemType SymbolicLink -Path "C:\path\to\workspace\data\plugins\my-plugin" -Target "D:\MyCodingProjects\my-plugin"
  ```

### 1.2 启动热构建
在插件根目录运行：
```bash
pnpm run dev
```
构建器会持续监听 `src/` 变更并重新打包至 `dist/`。在思源客户端中通过 `F5` 或「设置 → 插件 → 重新加载」即可实时查看效果。

### 1.3 调试控制台
- 按快捷键 `Ctrl+Shift+I`（Windows/Linux）或 `⌥⌘I`（macOS）打开思源内置的 Chromium DevTools。
- 查看 Console 输出、网络 Network 请求与 DOM 树。

## 2. 集市发布规范与 plugin.json 清单

思源集市（Bazaar）对插件元信息有明确的格式与质量要求：

| 字段 | 约束与要求 |
|---|---|
| `name` | 必须全局唯一，且**与 GitHub 仓库名严格一致**（全小写、中划线） |
| `version` | 严格遵守语义化版本（SemVer，如 `1.0.0`），每次发版必须递增 |
| `minAppVersion` | 必须填入该插件依赖特性的最低思源版本（如 `"3.8.3"`） |
| `displayName` / `description` | 推荐包含 `default`、`zh_CN`、`en_US` 等 BCP 47 标准语言标签 |
| `icon` | 插件图标（`icon.png` 或 WebP，尺寸不低于 128x128，透明背景） |
| `preview` | 插件界面预览图（`preview.png`、WebP 或 AVIF，比例推荐 16:9，不低于 1280x720） |
| `funding` | 赞助信息，推荐使用 `custom` 数组或 `links: Array<{ name: string, link: string }>` |
| `kernels` | 若包含内核 Goja 插件，配置 `["all"]` 或指定架构 |

## 3. 生产打包与发版流水线

```mermaid
graph LR
    Lint[1. 类型与语法检查] --> Build[2. pnpm run build 生成 package.zip]
    Build --> Release[3. 创建 GitHub Release 上传 zip]
    Release --> Bazaar[4. 首次向 bazaar 提交 PR]
```

### 步骤 1：质量与静态检查
```bash
pnpm run typecheck
npx eslint src/
```

### 步骤 2：打包生成 package.zip
```bash
pnpm run build
```
打包脚本会将 `dist/index.js`、`dist/kernel.js`、`dist/index.css`、`plugin.json`、`icon.png`、`preview.png`、`README*.md`、`i18n/` 自动压缩打包为根目录的 `package.zip`。

> [!IMPORTANT]
> 检查 `package.zip` 内根目录结构，**切勿包含 `node_modules/`、`.git/` 或未编译的 `src/` 源码**。

### 步骤 3：发布 GitHub Release
1. 在 GitHub 仓库页面创建新的 Release。
2. Tag 名称与 `plugin.json` 的 `version` 保持一致（例如 `v1.0.0`）。
3. **将编译打包生成的 `package.zip` 作为附件上传至 Release Assets**。

### 步骤 4：集市索引登记（仅首次发版）
1. Fork 官方集市仓库 `siyuan-note/bazaar`。
2. 在 `plugins.json` 数组中添加当前插件的仓库引用：
   ```json
   {
     "repo": "YourGitHubUsername/my-plugin",
     "icon": "https://raw.githubusercontent.com/YourGitHubUsername/my-plugin/main/icon.png"
   }
   ```
3. 向官方提交 Pull Request。审核合并后，插件将自动展示在思源笔记集市中。
