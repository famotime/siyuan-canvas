- 适用版本：SiYuan `v3.8.3` / `petal v1.2.7`（支持 `v1.2.8-preview` 特性）
- 最后核对：2026-09-13
- 稳定性：stable
- 权威来源：

## 1. 核心事件分类演进

SiYuan v3.8.3 将事件总线进一步扩充至 39 项，按业务场景归类如下：

### 1.1 编辑器状态与生命周期
- `loaded-protyle-static`：编辑器内容静态 DOM 首次渲染完成。
- `loaded-protyle-dynamic`：编辑器滚动动态异步加载内容完成。
- `switch-protyle`：焦点在多编辑器、多页签或分屏之间切换。
- `switch-protyle-mode`（新增）：编辑器在“编辑模式”与“预览模式”之间切换。
- `destroy-protyle`：编辑器实例销毁与资源释放。
- `code-language-update` / `code-language-change`：代码块编程语言识别与切换。

### 1.2 交互与右键菜单扩展
- 块与标题：`click-blockicon`、`click-editortitleicon`、`click-editorcontent`
- 上下文菜单拦截：`open-menu-content`、`open-menu-doctree`、`open-menu-blockref`、`open-menu-av`、`open-menu-tag`、`open-menu-link`、`open-menu-image`、`open-menu-inbox`、`open-menu-fileannotationref`、`open-menu-breadcrumbmore`
- 通用弹窗：`common-menu-open`、`common-menu-closed`、`before-show-tooltip`、`before-hide-tooltip`

### 1.3 数据与资产流控制（支持拦截）
- `before-upload-assets`（新增）：在文件上传至工作空间 assets 目录前触发，监听器返回 `false` 可直接阻断上传。
- `paste`：剪贴板内容粘贴事件，配备 120 秒异步等待限制，支持自定义格式预处理。
- `before-search-results-render`（新增）：搜索结果列表渲染前触发。

### 1.4 云端同步与内核插件
- `sync-start` / `sync-end` / `sync-fail`：数据跨设备同步状态追踪。
- `kernel-plugin-state-change`（新增）：内核独立插件加载、重载或状态变更通知。
- `opened-notebook` / `closed-notebook`（新增）：工作空间笔记本打开或关闭。

## 2. 监听与解绑最佳实践

```ts
import { Plugin } from "siyuan";

export default class EventDemoPlugin extends Plugin {
  // 1. 使用箭头函数作为实例属性，保证 this 指向正确且方便精确解绑
  private readonly onEditorSwitch = (e: CustomEvent<any>) => {
    console.log("切换到编辑器:", e.detail.protyle.block.rootID);
  };

  private readonly onBeforeUpload = (e: CustomEvent<{ files: File[] }>) => {
    console.log("即将上传文件数量:", e.detail.files.length);
    // return false; // 如需拦截可返回 false
  };

  onload() {
    // 2. 注册监听
    this.eventBus.on("switch-protyle", this.onEditorSwitch);
    this.eventBus.on("before-upload-assets", this.onBeforeUpload);
  }

  onunload() {
    // 3. 必须在 onunload 中逐一解绑，避免跨插件生命周期的内存泄漏
    this.eventBus.off("switch-protyle", this.onEditorSwitch);
    this.eventBus.off("before-upload-assets", this.onBeforeUpload);
  }
}
```

## 3. 版本兼容性建议

- **事件存在性防御**：在早期版本兼容场景下，若触发的事件在老客户端不存在，`this.eventBus.on` 不会报错，但不会被调用。对于关键业务流，可通过 `this.app.plugins` 或版本判断进行功能回退。
- **避免耗时阻断**：对于 `before-upload-assets` 和 `paste` 等关键用户路径，异步逻辑应设置超时（如 `Promise.race`），避免长时间挂起阻塞用户操作。
