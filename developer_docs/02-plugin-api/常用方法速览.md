# 常用方法速览

- 适用版本：SiYuan `v3.8.3` / `petal v1.2.7`（支持 `v1.2.8-preview` 特性）
- 最后核对：2026-09-13
- 稳定性：stable
- 权威来源：
  - <https://github.com/siyuan-note/petal/blob/main/siyuan.d.ts>

## 1. 网络与通信

### `fetchSyncPost`

```ts
fetchSyncPost<T = any>(url: string, data?: any): Promise<IWebSocketData>
```

- **用途**：以 Promise 风格同步等待内核 API 响应，思源插件开发中最推荐的请求方式。
- **返回模型**：
  ```ts
  interface IWebSocketData {
    code: number; // 0 代表成功，非 0 代表失败
    msg: string;  // 错误信息
    data: any;    // 负载数据
  }
  ```

### `fetchPost`

```ts
fetchPost(
  url: string,
  data?: any,
  cb?: (response: IWebSocketData) => void,
  headers?: IObject
): void
```

- **用途**：异步回调风格调用内核接口，支持传入自定义 HTTP Headers。

## 2. 交互与用户提示

### `showMessage` / `hideMessage`

```ts
showMessage(text: string, timeout?: number, type?: "info" | "error", id?: string): void
hideMessage(id?: string): void
```

- **用途**：在右上角弹出系统消息提示条。
- **参数**：
  - `timeout`：自动消失毫秒数（默认 6000，`0` 为常驻）。
  - `type`：`"info"`（默认提示）或 `"error"`（红色错误告警）。
  - `id`：指定唯一 ID，用于通过 `hideMessage(id)` 手动关闭。

### `confirm`

```ts
confirm(
  title: string,
  text: string,
  confirmCallback?: (dialog: Dialog) => void,
  cancelCallback?: (dialog: Dialog) => void
): void
```

- **用途**：弹出原生确认模态框，用于执行破坏性操作（如批量删除文档、清空数据）前的阻断式确认。

## 3. 页面、窗口与环境判断

### `openTab`

```ts
openTab(options: {
  app: App;
  doc?: { id: string; zoomIn?: boolean };
  custom?: {
    icon: string;
    title: string;
    data?: any;
    id: string; // 对应 addTab 声明的 type
  };
  position?: "right" | "bottom";
  openNewTab?: boolean;
}): ITab
```

- **用途**：在编辑器主工作区分屏或以新页签打开文档、自定义插件面板。

### `getFrontend` / `getBackend`

```ts
getFrontend(): "desktop" | "desktop-window" | "mobile" | "browser-desktop" | "browser-mobile"
getBackend(): "windows" | "linux" | "darwin" | "docker" | "android" | "ios"
```

- **用途**：动态判断当前前端运行环境与操作系统内核平台，进行多端适配与降级。

### `adaptHotkey`

```ts
adaptHotkey(hotkey: string): string
```

- **用途**：将快捷键字符串按当前操作系统（如 macOS 与 Windows 的 `Ctrl` / `⌘`）进行自动转换和显示适配。

## 4. 密钥与安全变量 (v3.8.3+)

### `getSecret`

```ts
getSecret(name: string): string
```

- **用途**：按名称读取思源「设置 → 密钥和变量」中安全密钥库的明文值。
- **安全说明**：仅在本地管理员权限下可用，适合安全读取用户配置的大模型 API Key、第三方集成 Token 等。找不到时返回空字符串。

### `getVariable`

```ts
getVariable(name: string): string
```

- **用途**：按名称读取变量库中的明文变量值，用于非敏感业务全局配置。找不到时返回空字符串。

## 5. 动态挂载方法 (v3.8.3+)

### `addToolbarItem` / `removeToolbarItem`

```ts
addToolbarItem(item: IMenuItem): void
removeToolbarItem(name: string): void
```

- **用途**：动态向编辑器工具栏注册快捷按钮，思源会自动持久化并允许用户在「设置 → 外观 → 工具栏」中调整排序与自定义快捷键。

### `addBreadcrumbButton` / `removeBreadcrumbButton`

```ts
addBreadcrumbButton(options: {
  id: string;
  icon: string;
  title: string;
  callback: (event: MouseEvent, protyle: IProtyle) => void;
}): string
removeBreadcrumbButton(id: string): void
```

- **用途**：在文档编辑器顶部的面包屑导航栏右侧添加自定义操作按钮。

## 6. 生产级类型化请求封装示例

```ts
import { fetchSyncPost, showMessage } from "siyuan";

export class ApiError extends Error {
  constructor(public code: number, message: string, public endpoint: string) {
    super(`[SiYuan API Error ${code}] ${endpoint}: ${message}`);
    this.name = "ApiError";
  }
}

export async function requestKernelApi<T = any>(
  endpoint: string,
  payload: Record<string, unknown> = {}
): Promise<T> {
  const response = await fetchSyncPost(endpoint, payload);
  if (response.code !== 0) {
    showMessage(response.msg || `调用 ${endpoint} 失败`, 5000, "error");
    throw new ApiError(response.code, response.msg, endpoint);
  }
  return response.data as T;
}
```
