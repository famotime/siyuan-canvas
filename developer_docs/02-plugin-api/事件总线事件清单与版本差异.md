## 2. 关键事件拦截与操作规范

### 2.1 拦截资产上传 (`before-upload-assets`)

在 v3.8.3 中，插件可通过该事件检查将要上传的附件列表。如果需要阻断原生上传逻辑（例如实施文件类型白名单、体积校验或转由外部图床上传），回调函数直接返回 `false`：

```ts
this.eventBus.on("before-upload-assets", (e: CustomEvent<{ files: File[] }>) => {
  const invalidFile = e.detail.files.find(f => f.size > 50 * 1024 * 1024);
  if (invalidFile) {
    showMessage("单文件大小不能超过 50MB", 6000, "error");
    return false; // 拦截原生上传流程
  }
});
```

### 2.2 粘贴事件与 120 秒异步预算 (`paste`)

- 编辑器粘贴触发 `paste` 事件。
- 插件可监听并处理剪贴板内容（如格式清洗、自定义 Markdown 转换等）。
- 思源为异步粘贴监听器分配了最大 120 秒超时限制，超出该时间后即使 Promise 未决，思源也会回退至默认粘贴行为。

## 3. 规范要求

1. **配对解绑**：所有 `this.eventBus.on()` 必须在 `onunload()` 中通过 `this.eventBus.off()` 解绑。
2. **轻量执行**：避免在同步监听器中执行重度耗时计算，以免阻塞主界面打字渲染。
