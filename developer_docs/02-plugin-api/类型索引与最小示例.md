# 类型索引与最小示例

- 适用版本：SiYuan `v3.8.3` / `petal v1.2.7`（支持 `v1.2.8-preview` 特性）
- 最后核对：2026-09-13
- 稳定性：stable
- 权威来源：
  - <https://github.com/siyuan-note/petal/blob/main/siyuan.d.ts>

## 1. 核心类型清单

| 类型名称 | 所属模块 | 语义与作用 |
|---|---|---|
| `Plugin` | `siyuan` | 前端插件基类，封装生命周期与宿主挂载能力 |
| `App` | `siyuan` | 思源应用全局上下文实例，携带插件管理器与编辑器环境 |
| `IProtyle` | `siyuan` | 编辑器核心实例类型，包含 `block`、`element`、`model` 等状态 |
| `ICommand` | `siyuan` | 命令面板命令定义，支持快捷键与 `execute(context)` |
| `ICommandContext` | `siyuan` | **v3.8.3 统一命令上下文**，携带当前焦点 `protyle` |
| `IMenuItem` | `siyuan` | 菜单项与动态工具栏（`addToolbarItem`）通用项定义 |
| `IWebSocketData` | `siyuan` | 内核与插件通信标准响应信封结构（`{ code, msg, data }`） |
| `IAgentCapabilityEffects` | `siyuan` | AI Agent 能力副作用声明（`read`, `write`, `create`, `delete` 等） |

## 2. IWebSocketData 强类型校验模板

```ts
import type { IWebSocketData } from "siyuan";

export function assertOk<T = any>(res: IWebSocketData): asserts res is IWebSocketData & { code: 0; data: T } {
  if (res.code !== 0) {
    throw new Error(`[SiYuan API Error ${res.code}] ${res.msg}`);
  }
}
```

## 3. ICommand 统一上下文示例 (v3.8.3)

```ts
import { Plugin, ICommandContext } from "siyuan";

export default class CommandDemo extends Plugin {
  onload() {
    this.addCommand({
      langKey: "insertCustomTimestamp",
      hotkey: "⌥⌘T",
      // v3.8.3 统一推荐使用 execute 接收 ICommandContext
      execute: (context: ICommandContext) => {
        if (context.protyle) {
          console.log("命令在编辑器中触发，当前文档 ID:", context.protyle.block.rootID);
        } else {
          console.log("命令在非编辑器全局环境下触发");
        }
      },
    });
  }
}
```

## 4. 动态工具栏与面包屑最小示例 (v3.8.3)

```ts
import { Plugin, IProtyle } from "siyuan";

export default class ToolbarDemo extends Plugin {
  onload() {
    // 动态添加编辑器工具栏项
    this.addToolbarItem({
      name: "my-highlight-btn",
      icon: "iconSparkles",
      title: "快速高亮",
      click: (protyle: IProtyle) => {
        console.log("工具栏项点击，目标 protyle:", protyle);
      },
    });

    // 动态添加面包屑操作项
    this.addBreadcrumbButton({
      id: "my-breadcrumb-info",
      icon: "iconInfo",
      title: "文档属性",
      callback: (event: MouseEvent, protyle: IProtyle) => {
        console.log("面包屑按钮点击:", event, protyle.block.rootID);
      },
    });
  }

  onunload() {
    this.removeToolbarItem("my-highlight-btn");
    this.removeBreadcrumbButton("my-breadcrumb-info");
  }
}
```

## 5. 自定义块渲染器最小示例 (`customBlockRenders`)

```ts
import { Plugin } from "siyuan";

export default class CustomBlockDemo extends Plugin {
  onload() {
    this.customBlockRenders = {
      "metric-card": {
        render: (options: {
          element: HTMLElement;
          content: string;
          setContent: (content: string) => boolean;
        }) => {
          options.element.innerHTML = `<div class="metric-box">指标: <strong>${options.content}</strong></div>`;
          return () => {
            options.element.innerHTML = "";
          };
        },
      },
    };
  }
}
```

## 6. AI Agent 能力注册示例 (`addAgentCapability`)

```ts
import { Plugin, App } from "siyuan";

export default class AgentDemo extends Plugin {
  onload() {
    this.addAgentCapability({
      name: "calculate_statistics",
      title: "统计计算器",
      description: "对指定文档的字数与块数量进行统计汇总",
      inputSchema: {
        type: "object",
        properties: {
          rootID: { type: "string", description: "文档块 ID" },
        },
        required: ["rootID"],
      },
      actionEffects: {
        calculate_statistics: { read: true, write: false },
      },
      handler: async (args: Record<string, unknown>, app: App) => {
        const rootID = args.rootID as string;
        return {
          result: `文档 ${rootID} 统计完成：共包含 42 个内容块。`,
          structuredContent: { blockCount: 42 },
        };
      },
    });
  }
}
```
