## 1. `blocks` 内容块主表

`blocks` 表记录了工作空间中每一个结构化内容块的完整元数据：

| 字段名 | 类型 | 含义 | 说明与注意事项 |
|---|---|---|---|
| `id` | `TEXT` | 块唯一标识 | 全局唯一主键（形如 `20260913080000-xxxxxxx`） |
| `parent_id` | `TEXT` | 父块 ID | 文档根块此字段为空 |
| `root_id` | `TEXT` | 所属文档根块 ID | 用于以文档为维度的过滤与归集 |
| `hash` | `TEXT` | 块内容 SHA256 哈希 | 用于块级一致性校验与变更检测 |
| `box` | `TEXT` | 所属笔记本 ID | 对应工作空间的顶级笔记本标识 |
| `path` | `TEXT` | 存储文件相对路径 | 对应底层的 `.sy` 文件物理相对路径 |
| `hpath` | `TEXT` | 人类可读层级路径 | 包含笔记本与文档树中文名称的完整逻辑路径 |
| `name` | `TEXT` | 块名称 | 用户为块设置的命名 |
| `alias` | `TEXT` | 块别名 | 别名索引（搜索与双链提示支持） |
| `memo` | `TEXT` | 块备注 | 用户在块标中附加的备注文本 |
| `tag` | `TEXT` | 块内标签聚合 | 块内包含的所有 `#tag#`（以逗号或空格隔开） |
| `content` | `TEXT` | 纯文本内容 | 去除了所有 Markdown 标记的纯文字 |
| `fcontent` | `TEXT` | 首子块纯文本 | 容器块第一个子节点的纯文本内容 |
| `markdown` | `TEXT` | 完整 Markdown 源码 | 包含完整格式标记的内容序列化字符串 |
| `length` | `INTEGER` | 字符长度 | `fcontent` 的字数统计 |
| `type` | `TEXT` | **块主类型** | 见下方类型详述，v3.8.3 包含 `custom`、`tabs`、`tab` 等 |
| `subtype` | `TEXT` | 块子类型 | 标题级别（`h1`~`h6`）或列表类型（`o`/`u`/`t`） |
| `ial` | `TEXT` | 内联属性列表 | 原始 IAL 属性字符串（`{: id="xxx" custom-*="xxx"}`） |
| `sort` | `INTEGER` | 排序权重 | 在父容器中的相对排列次序 |
| `created` | `TEXT` | 创建时间戳 | 格式：`YYYYMMDDHHmmss` |
| `updated` | `TEXT` | 最后修改时间戳 | 格式：`YYYYMMDDHHmmss` |

### `blocks.type` 核心取值与对应 AST 映射

| `blocks.type` | AST 节点类型 (`TypeAbbr`) | 结构分类 | 说明 |
|---|---|---|---|
| `custom` | `NodeCustomBlock` | 叶子块 | **v3.8.x 插件自定义块**，由 `customBlockRenders` 渲染 |
| `tabs` | `NodeTabs` | 容器块 | **v3.8.x 选项卡容器块**（Spec 3），仅容纳 `tab` |
| `tab` | `NodeTabItem` | 容器块 | **v3.8.x 选项卡项**，包含普通内容块 |
| `callout` | `NodeCallout` | 容器块 | 提示卡片块 |
| `d` | `NodeDocument` | 容器块 | 文档根块 |
| `h` | `NodeHeading` | 叶子块 | 标题块（一至六级由 `subtype` 区分） |
| `p` | `NodeParagraph` | 叶子块 | 普通段落块 |
| `c` | `NodeCodeBlock` | 叶子块 | 代码块（编程语言由 `subtype` 标识） |
| `m` | `NodeMathBlock` | 叶子块 | 数学公式块 |
| `t` | `NodeTable` | 叶子块 | 表格块 |
| `l` | `NodeList` | 容器块 | 列表容器（有序 `o`、无序 `u`、任务 `t`） |
| `i` | `NodeListItem` | 容器块 | 列表项 |
| `b` | `NodeBlockquote` | 容器块 | 引述块 |
| `s` | `NodeSuperBlock` | 容器块 | 超级块（横排/竖排混排容器） |
| `av` | `NodeAttributeView` | 叶子块 | 属性视图（数据库） |
| `query_embed` | `NodeBlockQueryEmbed` | 叶子块 | SQL 嵌入块 |
| `iframe` | `NodeIFrame` | 叶子块 | 内嵌网页框架 |
| `widget` | `NodeWidget` | 叶子块 | 挂件块 |
| `tb` | `NodeThematicBreak` | 叶子块 | 分割线 |

## 2. `refs` 引用与双向链接表

| 字段名 | 类型 | 含义 |
|---|---|---|
| `id` | `TEXT` | 引用关系唯一记录 ID |
| `def_block_id` | `TEXT` | 被引用的目标块 ID（定义端） |
| `def_block_parent_id` | `TEXT` | 被引用块的父块 ID |
| `def_block_root_id` | `TEXT` | 被引用块所属的文档 ID |
| `def_block_path` | `TEXT` | 被引用块所属文档的相对物理路径 |
| `block_id` | `TEXT` | 引用发生所在的内容块 ID（发起端） |
| `root_id` | `TEXT` | 引用所在文档 ID |
| `box` | `TEXT` | 引用所在笔记本 ID |
| `path` | `TEXT` | 引用所在文档相对物理路径 |
| `content` | `TEXT` | 引用锚文本内容 |
| `markdown` | `TEXT` | 引用在源文本中的 Markdown 标记（形如 `((id 'anchor'))`） |
| `type` | `TEXT` | 引用类型（`ref_id` 等） |

## 3. `attributes` 属性键值表

| 字段名 | 类型 | 含义 |
|---|---|---|
| `id` | `TEXT` | 记录唯一 ID |
| `name` | `TEXT` | 属性键名（自定义属性必须以 `custom-` 开头） |
| `value` | `TEXT` | 属性文本值 |
| `type` | `TEXT` | 属性类型 |
| `block_id` | `TEXT` | 所属内容块 ID |
| `root_id` | `TEXT` | 所属文档根块 ID |
| `box` | `TEXT` | 所属笔记本 ID |
| `path` | `TEXT` | 所在文档物理相对路径 |

## 4. `assets` 资源表

| 字段名 | 类型 | 含义 |
|---|---|---|
| `id` | `TEXT` | 资源记录唯一 ID |
| `block_id` | `TEXT` | 引用该资源的块 ID |
| `root_id` | `TEXT` | 所在文档 ID |
| `box` | `TEXT` | 所在笔记本 ID |
| `docpath` | `TEXT` | 所在文档物理路径 |
| `path` | `TEXT` | 资源相对路径（形如 `assets/image-20260913.png`） |
| `name` | `TEXT` | 原始文件名 |
| `title` | `TEXT` | 附件标题（可选） |
| `hash` | `TEXT` | 资源文件二进制哈希 |

## 5. `spans` 行内样式与标记表

| 字段名 | 类型 | 含义 |
|---|---|---|
| `id` | `TEXT` | 标记记录唯一 ID |
| `block_id` | `TEXT` | 所属内容块 ID |
| `root_id` | `TEXT` | 所属文档 ID |
| `box` | `TEXT` | 所属笔记本 ID |
| `path` | `TEXT` | 所属文档路径 |
| `content` | `TEXT` | 行内标记的文本内容 |
| `markdown` | `TEXT` | 包含行内语法的原始文本 |
| `type` | `TEXT` | 标记类型（`tag`、`textmark`、`code`、`strong` 等） |
| `ial` | `TEXT` | 行内样式属性（如自定义字体颜色） |
