> 文档创建日期：2026-11-13

## 二、核心隐式状态机分析与修复设计

### 1. 手势、滚轮与小地图交互（`SM-01` ~ `SM-02`）
- **现状问题**：
  - `startPointerGesture` 在 `window` 监听 `pointermove`/`pointerup` 时，缺少 `pointercancel`、`window.blur` 和 `pointerId` 匹配；连线拖拽（`startConnectionDrag` / `startEdgeEndpointDrag`）未标记 `isDragging`；单次拖拽无最小位移门槛且按 200ms 停顿切分撤销记录。
  - `watch(() => stageRef.value)` 未移除旧 DOM 上的 `touchstart`/`touchmove`；捏合缩放使用 `.toFixed(2)` 截断；`wheelSourceClassifier.reset()` 未接入生命周期重置；小地图拖拽也缺少 `pointerId` 与失焦保护。
- **优化方案**：
  - 在 `use-canvas-editor-gestures.ts` 中引入显式手势会话状态（含 `kind`、`pointerId`、`hasMoved`、`initialSnapshot`），统一在 `finishPointerGesture` 中清理 `pointermove`/`pointerup`/`pointercancel`/`blur` 与重置 `wheelSourceClassifier`；拖拽期间仅更新文档，在 `pointerup` 且 `hasMoved` 时以起止状态一次性落入 `history`；让连线/重连共享 `isDragging` 锁定自动保存。
  - 对 `stageRef` 使用 Vue `onCleanup` 移除旧 touch 监听；去除捏合缩放冗余 `.toFixed(2)`；在小地图组件补齐 `pointerId`、`blur` 与卸载清理。

### 2. 演示模式（`SM-03`）
- **现状问题**：
  - `togglePlay()` 先取反 `isPlaying` 再检查路径并隐式跳进 `startRecordedPlayback`；`CanvasPresentationController.vue` 仅检查 `availableNextNodes.length === 0`，在录制回放模式下会误禁“下一步”；`clearRecordedPath` 在 `readonly` 下直接改写持久化数据；长按 timer 未绑定取消清理。
- **优化方案**：
  - 在校验有效目标后再切换 `isPlaying`，且仅当处于 `recorded` 模式（或当前无任何激活起点但主动播放录制）时明确启动录制回放，不强行覆盖用户当前选定的图谱节点浏览；扩展 `canGoNext` / `canGoPrev` 计算属性统一覆盖图谱和录制模式；`clearRecordedPath` 仅清草稿或在非只读/退出时持久化，或提供明确的录制草稿重置语义；在控制器组件补充 `pointercancel` 与 `onBeforeUnmount` 清理定时器。

### 3. 文档保存并发、历史栈与工作区迁移（`SM-04` ~ `SM-05`）
- **现状问题**：
  - `saveInFlight` 拦截并直接丢弃并发保存；`silentSaveWorkspace` 传 `direct: true` 跳过冲突比对；`undo`/`redo` 忽视只读态和搜索通知；文件重命名触发 `watch(() => state.filePath, clearHistory)` 清空 Undo；目录重命名中途出错无回滚。
- **优化方案**：
  - 将 `saveInFlight` 升级为串行保底队列：若保存进行中再次收到 `save()` 或 `silentSave()`，标记待补存请求（保留最高模式要求），当前请求完成后自动续存一次；`silentSaveWorkspace` 移除 `direct: true`，保留外部修改检测；`undo`/`redo` 校验 `!readonly.value` 并同步触发 `notifyCanvasSearchChanged`；提供内部 `replaceFilePathWithoutClearingHistory` 供重命名/移动使用；`renameWorkspaceFolder` 在部分写入失败时回滚已写入目标文件再中止。

### 4. 内联编辑、边标签与 Query 运行时（`SM-06` ~ `SM-08`）
- **现状问题**：
  - `commitTextNodeEditing` 覆盖 Query SQL；`watch(editingMarkdown)` 提前设置 `isDirty = true` 导致定时自动保存写回旧文档后清掉脏标记；`updateEditingEdgeLabel` 每键入库破坏 `Escape` 取消语义；`fetchQueryResult` 无取消/世代校验；`saveQueryEditing` 拆成 3 次 Undo。
- **优化方案**：
  - 移除 `commitTextNodeEditing` 中遗留的 `query` 分支与 `watch(editingMarkdown)` 中的提前标脏；增加 `commitActiveTextEdit()` 或在未退出编辑态时挂起 `isDirty` 清空（优先实时同步文本或保存前先提交草稿）；边标签仅在草稿 ref 上编辑，确认提交时一次性写入历史，`Escape` 干净还原；`query-node-runtime.ts` 增加节点级 `AbortController` 与请求版本号，并将 `saveQueryEditing` 合并为单次更新。

### 5. 快捷键、弹窗、选择器与检查器（`SM-09` ~ `SM-12`）
- **现状问题**：
  - `Escape` 未考虑上层模态对话框与内联编辑；`loadSproutRelations`、`updateFilePickerQuery` 无异步世代守卫；`canvas-file-picker-dialog.ts` 在空列表按方向键产生 `-1` 越界且未区分加载失败；`CanvasInspector.vue` 仅 watch `selectedNode` 遗漏多选变更。
- **优化方案**：
  - 为 `createCanvasEditorKeyboardHandler` 注入 `hasOpenModal` 与 `isEditingNode` 门控；为异步查找函数添加请求版本校验；`canvas-file-picker-dialog.ts` 区分 `loading`/`ready`/`error` 并钳位 `activeIndex`；`CanvasInspector.vue` 监听完整 `selectedNodeIds` 序列。

### 6. 异步生成转换、原生渲染与全局单例生命周期（`SM-13` ~ `SM-16`）
- **现状问题**：
  - `handleAiSearch` 与 `convertSelectionToDocument` 在长耗时操作跨文件/卸载后仍可能写回或遗留孤儿文档；`protyle-native-render.ts` 失败 `<script>` 阻塞重试；`block-jump-highlight.ts` 单例销毁破坏其余 Tab；`plugin-settings-panel.ts` 监听器与 `CanvasWorkspace.vue` Blob 缓存回收不及时。
- **优化方案**：
  - 对 AI 探索与选区转换绑定目标 `(filePath, generation)` + `AbortController`，卸载时中止、创建文档后失败时尝试清理回滚；`protyle-native-render.ts` 使用显式 `Promise` 状态机并在失败时移除坏 `<script>`；`block-jump-highlight.ts` 对全局 `<style>` 使用引用计数；`plugin-settings-panel.ts` 使用 `MutationObserver`/容器清理主动解除 `window` 监听；Blob URL 缓存按 key 增量回收旧 URL。

2. **阶段 2（演示模式）**：`SM-03` → 补全测试并验证通过后独立提交。
3. **阶段 3（保存队列、历史与工作区原子性）**：`SM-04`、`SM-05` → 补全测试并验证通过后独立提交。
4. **阶段 4（内联编辑、边标签与 Query 运行时）**：`SM-06`、`SM-07`、`SM-08` → 补全测试并验证通过后独立提交。
5. **阶段 5（键盘模态栈、选择器与检查器）**：`SM-09` ~ `SM-12` → 补全测试并验证通过后独立提交。
6. **阶段 6（异步事务与全局资源回收）**：`SM-13` ~ `SM-16` → 补全测试并验证通过后独立提交。
7. **阶段 7（文档刷新）**：更新本表全部状态、关联提交记录与最终全量测试/Lint/构建结果。
